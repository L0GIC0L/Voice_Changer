# GLaDOS Voice Changer

A real-time voice changer application built with PyQt6, sounddevice, and pedalboard.

## Requirements
- Python 3.8+
- System packages: `libportaudio2`, `portaudio19-dev`, `libxcb-cursor0`
- Python packages: `PyQt6`, `sounddevice`, `pedalboard`, `numpy`

## Installation
1. Install system requirements:
   ```bash
   sudo apt-get install libportaudio2 portaudio19-dev libxcb-cursor0
   ```
2. Install Python requirements:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the application:
```bash
python main.py
```
